TESTS A COPIER-COLLER DANS CYGWIN
(se placer d'abord dans le dossier TP3 : cd /cygdrive/c/.../TP3)

=== 1. PROGRAMME AVEC MENU ===

flex tp3_menu.l && gcc lex.yy.c -o tp3_menu && ./tp3_menu

Dans le menu : taper un numero (1 a 8), puis
  - Entree         = fichier de test par defaut
  - un nom         = un autre fichier
  - k              = saisie au clavier (terminer par une ligne contenant seulement un point)

Test automatique de tous les choix du menu (sans rien taper) :

printf '1\n\n2\n\n3\n\n4\n\n5\n\n6\n\n7\n\n8\n\n0\n' | ./tp3_menu

Test avec saisie clavier simulee (ex 1.3 d, 3 mots) :

printf '8\nk\nabab\nabba\nbbabb\n.\n0\n' | ./tp3_menu


=== 2. TESTS SEPARES (un exercice a la fois, sans fichier de test) ===

--- Ex 1.1 a) ---
flex ex1_1a.l && gcc lex.yy.c -o ex1_1a
printf 'for( i=0; i < 10; i++ ) {\n truc[i] = 0;\n machin = 12.3;\n bidule = .0;\n}\n' | ./ex1_1a

--- Ex 1.1 b1) ---
flex ex1_1b1.l && gcc lex.yy.c -o ex1_1b1
printf 'for( i=0; i < 10; i++ ) {\n truc[i] = 0;\n machin = 12.3;\n}\n' | ./ex1_1b1

--- Ex 1.1 b2) ---
flex ex1_1b2.l && gcc lex.yy.c -o ex1_1b2
printf 'for( i=0; i < 10; i++ ) {\n truc[i] = 0;\n machin = 12.3;\n bidule = .0;\n x = 1e5;\n}\n' | ./ex1_1b2

--- Ex 1.2 ---
flex ex1_2.l && gcc lex.yy.c -o ex1_2
printf 'int x; /* commentaire */\n/* multi\nligne */ int y;\nprintf("a /* pas un commentaire */");\n' | ./ex1_2

--- Ex 1.3 a) 5 voyelles dans l'ordre (attendu : abstemious, facetious, aeiou) ---
flex ex1_3a.l && gcc lex.yy.c -o ex1_3a
printf 'abstemious\nfacetious\naeiou\nsequoia\nbanane\n' | ./ex1_3a

--- Ex 1.3 b) commence ou finit par a (attendu accepte : a ab ba abb ; rejetes : b bab bbb) ---
flex ex1_3b.l && gcc lex.yy.c -o ex1_3b
printf 'a\nb\nab\nba\nbab\nbbb\nabb\n' | ./ex1_3b

--- Ex 1.3 c) pas 2 lettres identiques consecutives (attendu : a b ab abab baba babab ; rejetes : abba bb aab) ---
flex ex1_3c.l && gcc lex.yy.c -o ex1_3c
printf 'a\nb\nab\nabab\nbaba\nabba\nbb\naab\nbabab\n' | ./ex1_3c

--- Ex 1.3 d) pas de sous-chaine aba (attendu accepte : a b ab abba bbaa abb bbabb ; rejetes : aba abab baba bab abaa) ---
flex ex1_3d.l && gcc lex.yy.c -o ex1_3d
printf 'a\nb\nab\naba\nabab\nabba\nbbaa\nbaba\nabb\nbab\nbbabb\nabaa\n' | ./ex1_3d


=== 3. TOUT COMPILER D'UN COUP ===

for f in ex1_1a ex1_1b1 ex1_1b2 ex1_2 ex1_3a ex1_3b ex1_3c ex1_3d; do flex -o $f.c $f.l && gcc $f.c -o $f; done
flex -o tp3_menu.c tp3_menu.l && gcc tp3_menu.c -o tp3_menu
